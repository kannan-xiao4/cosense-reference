# 検証範囲

| 検証 | 確認方法・状態 |
| --- | --- |
| 入力・認証境界・読み取り・編集フロー | 架空データを使った自動テスト |
| TypeScriptとWorker出力 | 型チェック・ビルド・出力のスモークテスト |
| 元の個人用Siteの読み取り | 実接続で確認済み |
| この汎用版の新規Siteへの配備 | 利用先の環境で実接続テストが必要 |
| 実際のページ書き込み | 自動テストはモックを使用。実接続は別途確認が必要 |

`npm run check` で自動テスト、型チェック、ビルド、スモークテスト、公開対象ファイルの簡易検査を実行できます。

`npm run check:public` は既知の識別子・認証情報形式の一部を検出する補助です。未知の秘密値を網羅して検出するものではありません。

新しいSiteでは、[再現手順](sites-setup.md)に従って、所有者専用のアクセス制御とMCP経由の読み取りを確認してください。書き込みを有効にする場合は、テスト用ページで作成・更新・削除を確認してください。
