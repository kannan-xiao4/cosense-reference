# 公開前レビュー

この版は、まず所有者のプライベートリポジトリで内容を確認するためのものです。公開への切替は行いません。

## この参考版で行ったこと

- 本番Siteから自作MCP処理と架空データのテストだけを抽出。
- 個人のCosenseプロジェクト名をサーバー環境変数へ移動。
- 読み取り専用を既定とし、書き込みには明示設定を要求。
- 本番SiteのID・URL・専用プラグインIDを除外。
- `.env`・PAT・取得ページ・ログ・ビルド成果物・元のGit履歴を除外。
- Sitesスターター、内部ヘルパー、依存ライブラリのソースを再配布せず、独立した最小ビルドを用意。
- 実装とSitesの認証基盤の境界を説明。
- 本番データに接続しないテストと、公開ファイルの簡易検査を追加。

`npm run check:public` は既知の識別子・認証情報形式の一部を検出する補助です。未知の秘密値や権利上の問題がないことを保証しません。

## 所有者が確認すること

- コード・ドキュメントの説明と公開範囲が意図に合うか。
- MITライセンス案でよいか。
- READMEに書いた機能・制限とブログの説明が一致するか。
- 新規の所有者専用Siteで、再現手順を実行できるか。
- 書き込みを紹介する場合、テスト用ページで実接続の作成・更新・削除を確認できたか。
- Git履歴やコミット作者に、公開したくないメールアドレスなどがないか。

実Siteを動かすための管理用資材は同梱していません。Sitesが機能提供する認証やホスティングを、このコードだけで再現できるという説明にはしません。

## 検証の区別

| 検証 | この版の扱い |
| --- | --- |
| 入力・認証境界・読取・編集フロー | 架空データの自動テスト |
| TypeScriptとWorker出力 | 型チェック・ビルド・出力のスモークテスト |
| 個人用Siteの読み取り | 元の実装で接続確認済み |
